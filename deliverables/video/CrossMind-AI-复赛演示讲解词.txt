大家好，我们是 Agent Forge 团队。我们的复赛作品是 CrossMind AI，一款面向跨境电商卖家的 AI 跨境选品分析助手。

跨境卖家在判断一个新品是否值得进入时，通常要分别查看趋势、竞品价格和大量用户评论，再依靠经验整理产品定位、定价和营销建议。信息分散、耗时长，而且结论很难解释。CrossMind AI 希望把这项工作从数小时压缩到十分钟以内，并输出一份可以直接讨论和执行的市场进入报告。

首页只需要两个输入：商品名称和目标市场。这里使用 Portable Blender，也就是便携榨汁杯，目标市场是美国 Amazon。点击开始分析后，后端立即创建异步任务，页面不需要等待一个很长的模型请求。右上角会明确显示当前模型模式：配置赛事 Token Plan 时显示 qwen3.7-plus REAL AI；没有 Key 时自动使用 DEMO SAFE MODE，保证评审仍能完整体验。

系统不是把所有问题一次性丢给大模型，而是编排四个职责清晰的 Agent。市场趋势 Agent 结合月度搜索增长和年度市场增长计算趋势与机会分；竞品 Agent 评估竞品数量、平均价格和差异化空间；用户评论洞察 Agent 从评论中提取电池、清洗、动力和密封等高频问题；最后由商业策略 Agent 综合前三步结果，给出产品定位、定价区间和营销方向。每个 Agent 都有独立状态、结构化 JSON 和即时结论，并写入数据库，因此整个过程是可观察、可追踪的。

分析完成后，系统自动进入商品市场进入报告。示例商品的市场机会评分是八十六分，趋势为增长，竞争程度为中等。核心结论是：值得差异化进入，开发面向旅行与健身场景的长续航、易清洗便携榨汁杯。报告不仅给判断，也展示判断依据。用户痛点包括续航不足、刀头清洗困难、处理冰块动力不足以及杯盖渗漏。产品建议进一步落到五千毫安时电池、可拆卸刀头、自清洁模式和强化密封；定价建议依据竞品均价给出合理首发区间；营销建议聚焦旅行、健身和办公室三个场景。报告可以通过浏览器直接导出 PDF，方便团队评审和留档。

技术上，前端采用 Vue 三、Vite、Element Plus、Axios 和 ECharts。后端采用 Java 二十一与 Spring Boot 三，使用 PostgreSQL 保存分析任务和每个 Agent 的结果，Redis 为后续缓存、锁和任务队列预留。Controller 只负责 HTTP 请求，AnalysisService 管理任务生命周期，AgentOrchestrator 负责四阶段编排，模型调用统一经过 LLMClient。赛事 Token Plan 使用 OpenAI 兼容协议连接 qwen3.7-plus；MockLLMClient 提供确定性兜底。API Key 只通过环境变量注入，不会出现在仓库、页面或健康接口。

项目提供单镜像生产构建和 Docker Compose 一键编排。评审可以复制环境变量示例后执行一条命令，同时启动 Web、API、PostgreSQL 和 Redis。即使没有模型 Key，也能复现完整的多 Agent 流程。仓库还包含自动化后端测试、前端生产构建、系统架构、演示脚本和可复现 Mock 数据。

下一阶段，我们会接入合规的趋势、广告和评论数据源，增加引用溯源、多商品对比、Agent 重试与成本监控，并邀请真实卖家验证节省时间、建议采纳率和付费意愿。

CrossMind AI 的价值不是再做一个聊天窗口，而是把复杂、分散的选品研究变成一个可解释、可执行、可复现的 Agent 决策流程。谢谢各位评委。
