# 黑客松提交材料

## 项目名称

CrossMind AI —— AI 跨境选品分析助手

## 一句话介绍

输入商品与目标市场，让四个 AI Agent 自动完成趋势、竞品、评论与商业策略分析，生成可执行的市场进入报告。

## 参赛方向

AI + 跨境电商 / Multi-Agent 商业决策辅助

## 项目简介（可直接用于报名表）

跨境卖家在选品阶段通常需要在多个工具和页面之间研究市场趋势、竞品价格与用户评论，不仅耗时，也很难将零散数据转化为统一、可执行的进入策略。CrossMind AI 将选品分析拆分为市场趋势、竞品分析、用户洞察和商业策略四个专业 Agent。用户输入商品与目标市场后，可实时看到 Agent 协作过程，并获得包含机会评分、竞争程度、用户痛点、产品改进、定价和营销建议的结构化报告。系统支持阿里云百炼，并通过统一 LLM 接口保留 OpenAI 与本地模型的扩展能力；没有 API Key 时也能依靠内置 Mock 数据稳定完成全流程演示。

## 解决的核心问题

- 降低跨境选品前期研究的时间成本。
- 将分散的市场、竞品和评论信息转化为单一决策报告。
- 让 AI 的执行过程可观察，避免只有一个不可解释的聊天答案。
- 通过离线演示能力降低黑客松现场的网络和模型风险。

## 亮点

1. **真实 Multi-Agent 流程**：四个 Agent 有独立任务记录、状态和结构化输出。
2. **完整产品闭环**：从输入、分析动画、报告到 PDF 导出均可演示。
3. **模型可替换**：业务 Agent 仅依赖 `LLMClient`，百炼和 Mock 可按配置切换。
4. **可复现**：内置商品、评论和竞品 Mock 数据，不依赖实时爬虫。
5. **工程化实现**：前后端分离、异步任务、数据库持久化、自动化测试和 CI。

## 演示案例

- 商品：Portable Blender
- 市场：USA Amazon
- 目标：判断是否值得进入市场
- 输出：86/100 机会评分、增长趋势、中等竞争、续航与清洗痛点，以及产品、定价和营销策略。

## 技术栈

Vue 3、Vite、Element Plus、ECharts、Java 21、Spring Boot 3、Spring Data JPA、PostgreSQL、Redis、阿里云百炼。
